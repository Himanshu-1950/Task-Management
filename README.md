# Task Management

A simple Task Management application to organize and track daily tasks
efficiently.

## 📌 About the Project

This project is designed to help users manage their tasks with basic
CRUD (Create, Read, Update, Delete) functionality.\
It includes both backend and frontend components for a complete working
application.

## 🚀 Features

-   Add new tasks
-   View all tasks
-   Update existing tasks
-   Delete tasks
-   Backend API integration
-   Clean and simple user interface

## 🛠️ Tech Stack

-   Python (Backend)
-   JavaScript (Frontend)
-   HTML & CSS
-   Node.js
